音乐播放器

用 Qt6 写的一个桌面音乐播放器，QML 搭界面，C++ 写逻辑。

能干什么

播放 mp3、wav、flac、ogg、m4a 这些格式的本地音频，支持歌词同步显示。

具体功能：播放暂停停止、拖进度条、调音量、鼠标滚轮也能调音量、点一下静音再点恢复原来的音量、空格键控制播放暂停、上一首下一首、列表循环单曲循环随机播放三种模式。

歌词支持 LRC、VTT、zh.vtt 三种格式，没有歌词文件就显示纯文本。当前唱到哪一行会自动高亮并居中滚动，点一下歌词行可以直接跳过去。

播放列表可以添加文件，也能直接把文件拖进去。侧边栏式面板，右边滑出来，选歌自动收回去。hover 到列表项上会出现删除按钮，删的是正在放的歌会先停掉。

能读歌曲的标题、艺术家、专辑信息。播放出错了也会有提示。装完以后系统菜单里搜"音乐播放器"就能启动。

代码结构

PlayerController 管播放和元数据，PlaylistModel 管播放列表，LyricsModel 管歌词数据，LyricsParser 管 LRC/VTT 文件解析。C++ 类通过 QML_ELEMENT 自动注册到 QML。构建用 cmake，指针输入全部用 TapHandler 和 WheelHandler，没有 MouseArea。


开发过程

一开始用 QWidget 搭了个壳，后来趁着重构全部换成了 QML。

换完以后把原来堆在一起的代码拆开了：播放控制、列表管理、歌词解析各管各的。中途遇到的问题包括 QML 加载路径不对、中文路径编码、VTT 多行文本合并、Qt 的 isCurrent 绑定不刷新、GCC16 编译器崩溃等等，一个个修过来了。

功能上陆陆续续加了拖放、播放模式、侧边栏面板、音量控制、错误提示、键盘快捷键、歌词点击跳转、静音记忆、列表删除。最后补了桌面文件和安装配置，算是能独立用了。
